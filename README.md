Hi! The Juyter Notebook is intended to generate the intermediate data files as you go (which you then put into the sky catalog websites).
In principle, the only data you need is CDSX-Match.csv, located in /data-files. Make sure it's taken out of the subfolder and in the same folder as xmatch.ipynb before running!
If you want to just generate graphs, drag the files in from the examples folder, comment out the "write_to" lines, and you're all set!
